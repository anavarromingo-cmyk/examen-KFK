# 🥋 Ki Full Katai - Dashboard de Exámenes

Sistema de seguimiento de progreso para exámenes de artes marciales Ki Full Katai.

![Dashboard Preview](https://img.shields.io/badge/Firebase-Enabled-orange?style=for-the-badge&logo=firebase)
![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Active-blue?style=for-the-badge&logo=github)

## 🌟 Características

- ✅ **Registro de Estudiantes** - Sistema de registro con selección de cinturón objetivo
- 📊 **Dashboard Personalizado** - Seguimiento individual de progreso
- 📝 **Registro Diario** - Ingreso de repeticiones por técnica y pierna
- 📈 **Visualización de Progreso** - Gráficos circulares y barras de progreso
- 🥋 **Guía de Técnicas** - Imágenes descriptivas de cada patada
- 📋 **Tabla de Requisitos** - Requisitos completos por cinturón
- 📥 **Exportación PDF** - Descarga reportes profesionales de progreso
- 👨‍💼 **Panel de Administrador** - Vista consolidada de todos los estudiantes
- ☁️ **Firebase Backend** - Almacenamiento en la nube con sincronización en tiempo real

## 🛠️ Tecnologías

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Backend:** Firebase (Firestore + Authentication)
- **PDF Export:** jsPDF + autoTable
- **Hosting:** GitHub Pages

## 🚀 Uso Local

1. Clona el repositorio:
```bash
git clone https://github.com/[tu-usuario]/ki-full-katai.git
cd ki-full-katai
```

2. Inicia un servidor local:
```bash
python3 -m http.server 8000
```

3. Abre `http://localhost:8000` en tu navegador

> **⚠️ Importante:** No abras `index.html` directamente con `file://` - Los módulos ES6 requieren HTTP/HTTPS.
